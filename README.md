# Community-wide annual tuberculosis symptom screening in Zambia
This repository contains the analysis code and aggregated datasets used to reproduce the main analyses for the manuscript:

**Community-wide annual tuberculosis symptom screening over four years: Findings from eight intervention communities of the HPTN 071 (PopART) cluster-randomized trial in Zambia**

## Overview
This study is a secondary analysis of intervention data collected during the HPTN 071 (PopART) trial in eight intervention communities in Zambia.

Community health workers conducted repeated rounds of household-based tuberculosis (TB) symptom screening alongside delivery of the PopART combination HIV prevention intervention.

The analyses describe:

- participation in annual community-wide TB symptom screening;
- the TB screening and diagnostic cascade across intervention rounds;
- TB yield by demographic and HIV-related characteristics;
- factors associated with newly diagnosed TB;
- associations between previous screening history and TB detection; and
- sensitivity analyses restricted to participants observed in the same zone across all three intervention rounds.

This repository has been created to support reproducibility of the analyses while complying with restrictions on sharing individual-level HPTN 071 (PopART) data.

## Data availability

The original individual-level HPTN 071 (PopART) intervention data are not included in this repository because they are subject to study data-sharing and governance restrictions.

Instead, the `data/` directory contains **aggregated datasets** that can be used to reproduce the main analyses presented in the manuscript.

The aggregate datasets contain counts stratified by the variables required for each analysis, including, where relevant:

- intervention round;
- community;
- intervention zone;
- age group;
- sex;
- HIV/ART status;
- household TB contact;
- residence and mobility status; and
- previous TB screening history.

No directly identifiable individual-level participant data are included in this repository.

## Analysis scripts

### `Aggregate_Data.R`

Documents the creation of the aggregated analysis datasets from the restricted individual-level HPTN 071 (PopART) data.

The original individual-level source dataset is not included in this repository. Therefore, this script requires authorised access to the source data to run from the beginning.

The aggregated datasets created by this script are provided in the `data/` directory so that the remaining analyses can be reproduced without access to the individual-level dataset.

### `Figure_1_TB_Cascade.R`

Reproduces the overall TB screening and diagnostic cascade across the three intervention rounds.

The cascade includes:

- household members listed;
- eligibility;
- participation;
- TB symptom screening;
- positive symptom screening;
- sputum collection;
- availability of laboratory results;
- newly detected TB; and
- reported initiation of TB treatment.

### `Figure_2_Panel_plot.R`

Reproduces the panel plots describing TB screening and TB yield across intervention rounds and participant characteristics.

### `Figure_3_TB_Cascade.R`

Reproduces the Round 3 TB screening cascade according to previous TB screening history.

Previous screening history is classified as:

1. first-time screening;
2. screened once previously in the same zone; and
3. screened twice previously in the same zone.

### `Figure_3_TB_Table.R`

Reproduces the regression analyses examining the association between previous TB screening history and newly diagnosed TB in Round 3.

The script also includes the sensitivity analysis restricted to participants observed in the same zone across all three intervention rounds.

### `Table_1_Summary.R`

Reproduces the descriptive characteristics of participants screened for TB across intervention rounds.

### `Table_2_analysis.R`

Reproduces the regression analyses examining factors associated with newly diagnosed TB.

Models include relevant combinations of:

- community;
- age;
- sex;
- HIV/ART status;
- household TB contact; and
- residence and mobility status.

Robust standard errors account for clustering within intervention zones.

## Statistical analysis

TB yield was calculated as:

```text
Number of newly diagnosed TB cases
----------------------------------- × 100,000
Number screened for TB
```

Regression analyses used logistic regression to estimate odds ratios and 95% confidence intervals.

Community was included in the regression models and robust standard errors accounted for clustering within intervention zones.

The adjusted analyses included prespecified participant characteristics including age, sex, HIV/ART status and household TB contact, with residence and mobility status included where available.

Sensitivity analyses included analyses of previous screening history among participants observed in the same zone across all three intervention rounds.

Penalised logistic regression was additionally used as a sensitivity analysis where appropriate.

## Reproducing the analyses

The analyses were conducted in R.

Required packages include:

```r
install.packages(c(
  "dplyr",
  "tidyr",
  "readr",
  "sandwich",
  "logistf",
  "forestploter",
  "flextable",
  "officer"
))
```

After cloning or downloading the repository, the public analyses can be run using the aggregated datasets contained in the `data/` directory.

For example:

```r
source("Figure_1_TB_Cascade.R")
source("Figure_2_Panel_plot.R")
source("Figure_3_TB_Cascade.R")
source("Figure_3_TB_Table.R")
source("Table_1_Summary.R")
source("Table_2_analysis.R")
```

`Aggregate_Data.R` requires authorised access to the original restricted individual-level dataset and is therefore included primarily to document how the public aggregated datasets were created.

The remaining scripts can be run using the aggregated datasets supplied in the repository.

## Aggregated regression data

For binary outcomes, regression analyses can be reproduced from grouped data when the aggregation retains the complete combination of covariates required by the model.

The regression datasets therefore contain, for each relevant covariate combination:

- the total number of participants; and
- the number diagnosed with TB.

This permits reproduction of the main regression analyses without releasing the original participant-level records.

Where required for penalised logistic regression, grouped counts can be expanded into analysis-equivalent binary observations corresponding to the same covariate patterns and outcome counts. These reconstructed observations are not the original participant records.
